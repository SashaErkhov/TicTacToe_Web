# Описание

## Наименование
TicTacToe_Web - Онлайн крестики-нолики 1 на 1 с личными аккаунтами, матчмейкингом и историей партий.

## Предметная область
База данных TicTacToe_Web предназначена для хранения информации о пользователях (их аккаунтах), историях матчей всех пользователей, историях всех ходов всех матчей, множестве текущих матчей. Система должна поддерживать: создание новых пользователей; их авторизация и аутентификация; создание и отслеживание матчей, и истории ходов внутри матча; выдачу истории матчей для конкретного пользователя, с фильтрацией. 

# Данные
